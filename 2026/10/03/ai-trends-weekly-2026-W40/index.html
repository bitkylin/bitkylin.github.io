⏪ 上周回顾

注：W39（09-21 ～ 09-27）报告未发布，本期为隔周回顾，对比基线为 2026-W38 报告。

上期报告的三大核心趋势在本期（隔两周）的进展：

  1. GPT-6 Astra 叙事从「发布冲击」演进为「家族化 + 性价比战」：W38 时 Astra 因需求过载暂停 Pro 新订、OpenAI 建立失准报告框架；本期 GPT-6 家族占据 HN 月榜前三两席（Astra 2279 分、Sol & Luna 1779 分），GPT-6.1 Sol 以「五分之一价格近 Astra 智能」（HN 1062 分/949 评 + Techmeme 头条）打响降价战，DevDay 同场发布常驻智能体 Dots 与 500 美元/月 Pro 计划；但 GPT-6.1 Astra 公测因未达安全标准被取消——「快发布」与「安全门」首次相撞。
  2. Agent Skills 连续统治，重心完成「造技能 → 自学习 + 安全验证」转移：W38 技能类占 GitHub 月榜约 1/3；本期 archify 仍居月榜第 2，Trendshift 恢复采集后 Claude Code 技能层全面爆发（autoharness、Karpathy-skills、mattpocock/skills 等），安全侧 SkillSpector、Claude-Red、iFixAi 同步上榜，HF Papers 的 SkillOpt/COLLEAGUE.SKILL 延续技能自进化研究——技能生态已长出「质检与蒸馏」基础设施。
  3. Qwen3.8 生态从「端侧化」走向「半壁江山」：W38 unsloth GGUF 763 万下载成全榜之王；本期 HF 模型月榜 30 席中 15 席构建在 Qwen/国产底座上（下载量 Top3 全部相关），Trendshift 周榜第 3 的 Strata 更把 Qwen3.8-Flash-Next（125B MoE）一键装进 12-24GB 显存的消费级电脑；Techmeme 侧 DeepSeek 联手华为开发昇腾编程工具（含开源 CUDA 替代），国产开源栈软硬协同加速。

连续上榜项目（隔一期 W39）：Agent Skills 生态（三源维持）、Qwen 生态（降为双源但底座占比升至 50%）、GPT-6 家族（热度上升）、语音智能体（VoiceStudio 双榜冠军）、反 AI 味治理（HN 双帖 + no-ai-slop）、Meta Muse（争议发酵）、Agent 安全（升级为监管事件）；DeepSeek 生态 W38 退出跨源验证后本期三线回归（详见文末交叉分析）。
